What the references change — and what they don’t

Keep the restraint

  • Familiar charcoal field Background #0A0A0A, matching Quackback’s dark base. Supporting surfaces lift just one step; the main list stays flush.
  • Hairline structure Columns and rows divide with #262626. Supporting blocks (boards, roadmap peek) use a 12px outlined panel. Lists stay continuous.
  • Type as hierarchy 20px / 600 page titles. 15px / 600 list titles. 14px body. 13px metadata in #A1A1A1.
  • Familiar controls, restrained rounding Buttons, search, and compact segments. Not filter rows, not form fields, not module toggles.
  • Solid icons, quiet selection Solid Heroicons throughout, matching the current admin rail. Active: a subtle neutral background and a small gold rail mark.
  • Underline tabs Trending / New / Top and portal product nav use a short gold underline.

Keep as Quackback

  • Icon-only admin rail Do not grow it into X’s labeled 275px column. The 56px rail stays.
  • Gold, not sky blue — and not a fill color Ticks, voted chevrons, unread counts, focus rings, tab underlines, and primary buttons. Not selected rows, not chat bubbles, not empty-state discs.
  • Existing columns and entry points Feedback keeps filters | list. Support keeps views | threads | detail. New post stays a header pill that opens the existing dialog — no tweet composer on the feed.
  • Workspace themes still win Unbranded default only. Branding CSS variables continue to override.
  • Light mode stays White field, #0A0A0A text, #E5E5E5 borders, same geometry. Toggle it on the devices below.

Critic rounds

What the first pass got wrong

  • Gold as a fill Selected rows had an 8% gold wash. Agent replies were gold bubbles. Empty state was a gold “?”. That makes gold a surface, not an accent. Rows are #181818. Replies are near-white pills. Empty uses a muted solid feedback icon.
  • X compose on the portal “What should we improve?” copied the tweet box. Quackback creates posts in a dialog from New post. The composer is gone.
  • Pills on everything Filter rows, settings fields, and module rows were capsules. The brief reserves pills for buttons, search, and compact segments. Fields are 12px. Filters are text rows. Modules are switches.
  • Invented mobile chrome A four-icon dock is not the admin app. Mobile admin is hamburger + Filters FAB, as today.
  • Crowded portal header Search moved to the right column, above Boards — X’s search slot, Quackback’s boards job.
  • Light mode was copy only Devices now toggle the white sibling so the geometry can be judged in both.
  • Status as a chip Notes said dot + label; the mock used outline pills. Status is a 6px dot and the status name.
  • Still out of scope No X logo, no verification, no Home label, no workflow-canvas restyle. Branding presets still override these defaults.
  • Round 3 · closer to Quackback Restored the current charcoal and gold, neutralized secondary text, softened headings to semibold, and embedded solid Heroicons. Quiet selected backgrounds and 12px supporting panels retain the minimal structure.

When you implement

  • globals.css + DEFAULT_*_BASE Keep the existing charcoal and primary tokens. Use quiet hairlines and flat list surfaces; preserve workspace theme overrides.
  • button, input, tabs, card, dialog, settings-card Keep pill buttons. Strip shadows. Card is border-only or flush. Line tabs are the page default. Inputs stay rectangular.
  • admin.tsx + admin-sidebar Drop the inset rounded main frame. Solid Heroicons. Gold tick on the active item.
  • Post rows, conversation rows, portal feed No per-item card. Hairline + #181818 hover. Vote control loses the muted box.
